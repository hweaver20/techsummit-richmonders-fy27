   - Rate limits: 1 call/min per user, 10 tokens/min per user

   NOTE: invalid_keywords was attempted but is NOT supported on these external-model
   endpoints (silently dropped by the AI Gateway API on both create and update; verified
   by reading the endpoint config back). The working data-protection guardrails are
   safety=true and pii (behavior=BLOCK).

   DATA-READ GUARDRAIL (prevents all Lakebase data from being read): databricks-gpt-5-6-luna
   carries an OUTPUT PII guardrail (guardrails.output.pii.behavior=BLOCK). When a runaway
   "dump every row of the customers table" request causes the model to emit customer PII
   (names, emails, phones, SSNs), the gateway BLOCKS the response before any data is
   returned: HTTP 400, finishReason=output_guardrail_triggered, pii_detection=true. This
   is a distinct block type from the input safety classifier, and is the guardrail that
   satisfies R2. Input safety is disabled on this endpoint so the request reaches the
   model and the OUTPUT guardrail evaluates the response (with input safety on, the
   request is blocked at input before the data-egress guardrail can run).
